# Work in Progress — Incomplete Features

This project is under active development. Several features referenced in the
codebase (routes, components, schemas, etc.) may be:

- Partially implemented (scaffolding exists, logic does not)
- Stubbed out with placeholder/mock data
- Present in name only (imported or referenced but not yet built)
- Mid-refactor, with old and new patterns coexisting

When exploring this repo:

- Don't assume a file, function, or route is production-ready just because
  it exists. Check for TODO/FIXME comments, empty function bodies, or
  hardcoded/mock return values before relying on it.
- If something looks broken or incomplete, it may genuinely be incomplete —
  not a bug you need to silently work around. Flag it or ask.
- Prefer checking recent commits/PR descriptions or asking the maintainer
  over assuming intended behavior from an unfinished implementation.
